# เครื่องมือฝ่ายผลิต

เว็บแอปรวมเครื่องมือสำหรับงานคอนกรีตผสมเสร็จ ใช้ได้ทันทีใน browser ไม่ต้องติดตั้งอะไร

- `index.html` หน้าหลัก ถ้าจะเพิ่มโปรแกรมใหม่ ให้เพิ่มรายการใน `TOOLS`
- `mix-design.html` + `mixdesign.js` โปรแกรม Mix Design ตาม ACI 211.1
- `dose.html` Mix Rev. Design (ปรับสูตรหน้างาน): เปลี่ยนปูน คงสัดส่วนน้ำยาต่อ binder แล้วคูณ cap เครื่องที่โหลด
- `convert.html` คำนวณผลกดลูกปูน kN ↔ ksc (ทรงกระบอก Ø15 ซม. / ลูกบาศก์ 15 ซม.)
- `core.html` + `coretest.js` ตรวจสอบผลกดลูกปูน Coring: L:D (ปรับตาม ASTM C42), ความหนาแน่น, กำลังอัด, % เทียบ Mix, Target 100%/85%, ตัดสินรายกลุ่มตาม ACI 318 (ตรวจเลขข้อตามฉบับที่ใช้) (เฉลี่ย ≥ 85%, ต่ำสุด ≥ 75%)
- `field.html` + `fieldreport.js` ใบรายงานสนามและเก็บก้อนตัวอย่าง (FM-PQ-10): สร้างงาน, สแกน/พิมพ์ D/O → หน่วยผลิตจากรหัส 3 หลักแรก, บันทึกอัตโนมัติในเครื่อง, ส่งออก/นำเข้าไฟล์สำรอง, Export PDF A4 แนวนอน 15 คัน/หน้า
- `fieldtools.js` สูตรคำนวณของสองหน้าข้างบน (ตามชีต Excel เดิม)
- `admixtures.js` รายการสารผสมเพิ่มที่ใช้ร่วมกันทุกโปรแกรม

วิธีใช้: เปิด `index.html` ใน browser (ต้องวางทุกไฟล์ไว้ในโฟลเดอร์เดียวกัน)

## Mix Design (ACI 211.1)
คำนวณสัดส่วนผสมคอนกรีตด้วยวิธี absolute volume ตาม ACI 211.1-91 หน่วย SI

## ขั้นตอนที่คำนวณ
1. f'cr ตาม ACI 318-19 §26.4.3: ถ้ามี S.D. จากผลทดสอบตั้งแต่ 15 ชุดขึ้นไปจะใช้สูตรจาก S.D. (ถ้าน้อยกว่า 30 ชุดจะคูณ factor เพิ่ม) ถ้าไม่มีใช้ f'c + 7.0 / 8.3 หรือ 1.10f'c + 5.0
2. น้ำและปริมาณอากาศจาก Table 6.3.3 (slump เลือกเป็น cm: 5, 7.5, 10, 12.5, 15, 17.5 ค่าน้ำ interpolate ระหว่างจุดกึ่งกลางของช่วง slump ในตาราง)
3. w/cm จาก Table 6.3.4(a) แบบ interpolate แล้วเทียบกับ w/cm สูงสุดด้านความคงทน และปริมาณวัสดุประสานขั้นต่ำ
   จากนั้นแบ่ง binder เป็นปูน, fly ash และ slag ตาม % โดยน้ำหนัก
4. ปริมาตรหินจาก Table 6.3.6 (b/b₀ ตาม FM ของทราย)
5. ทรายคำนวณจากปริมาตรที่เหลือ
6. ปรับน้ำหนักวัสดุตามความชื้นหน้างาน (§6.3.10) และคิดน้ำหนักชั่งสำหรับ trial batch
7. สารผสมเพิ่ม: ปริมาณ (cc) = binder (kg) × dose เช่น binder 100 kg × dose 3 = 300 cc
   น้ำที่อยู่ในสารผสม (100 − เนื้อสาร %) จะถูกหักออกจากน้ำที่ชั่ง

## สารผสมเพิ่ม (Sika)
ค่าจากเอกสาร PDS ของ Sika ประเทศไทย · ถ.พ. ใช้ค่ากลางของช่วงความหนาแน่น

| ผลิตภัณฑ์ | ASTM C494 | ความหนาแน่น (kg/L) | อัตราที่แนะนำ |
|---|---|---|---|
| Plastomix-704 | Type A/D | 1.060–1.100 | 300–800 cc/100 kg ซีเมนต์ |
| Sikament NN TH | Type F | 1.225–1.255 | 600–3,000 cc/100 kg ซีเมนต์ |
| Sikament G-5 | Type G | 1.180–1.200 | 800–2,500 cc/100 kg ซีเมนต์ |
| ViscoCrete-10 TH | ลดน้ำอย่างมาก (PCE) | 1.050–1.070 | 0.6–3.0% โดยน้ำหนักซีเมนต์ |

GCP Applied Technologies: DARACEM S21C (ASTM C494 Type F, naphthalene — ห้ามใช้ร่วมกับ PCE)
อยู่ในรายการแล้ว แต่ยังรอ PDS สำหรับ ถ.พ. และอัตราการใช้ · DARACEM 465 และ WRDA P120 ยังไม่ใส่
Concera SA 8689 (Type F, รหัส ADM0502) อยู่ในรายการ ยังรอ PDS

PDS ของ Sika ไม่ระบุเนื้อสาร (solid content) จึงตั้งค่าเริ่มต้นเป็น 100% (ไม่หักน้ำในสารผสม)

## สมมติฐานในหน้าเว็บ
- f'cr ใช้สูตรกรณีไม่มีข้อมูล S.D. เสมอ (หน้าเว็บไม่มีช่องกรอก S.D.)
- หินถือว่าอยู่สภาพ SSD ไม่ปรับน้ำ · ความชื้นทรายที่กรอก = ส่วนที่เกิน SSD ซึ่งจะถูกหักจากน้ำทั้งหมด
- หน้าเว็บไม่มีช่อง slag, w/cm สูงสุด, วัสดุประสานขั้นต่ำ และลดน้ำ (`mixdesign.js` ยังรองรับ)

## ข้อจำกัด
- ช่วงกำลังที่ใช้ได้ตามตาราง 6.3.4(a): f'cr 15–40 MPa (AE ถึง 35 MPa)
- ไม่รองรับการแปลงกำลังลูกบาศก์ → ทรงกระบอก
- ถ้าใช้ fly ash / slag ยังใช้ตาราง w/c ของปูนปอร์ตแลนด์ล้วน ต้องหาความสัมพันธ์ w/cm–กำลังจาก trial batch
- ไม่ได้นับปริมาตรเนื้อสารของสารผสมเพิ่มในการคำนวณ 1 m³ (มีผลน้อยมาก)
- ผลที่ได้เป็นค่าเริ่มต้นสำหรับ trial batch เท่านั้น ต้องทดลองผสมจริงและให้วิศวกรผู้รับผิดชอบอนุมัติก่อนนำไปใช้
