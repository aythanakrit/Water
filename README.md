## Mix Design (ACI 211.1)
คำนวณสัดส่วนผสมคอนกรีตด้วยวิธี absolute volume ตาม ACI 211.1-91 หน่วย SI

## ขั้นตอนที่คำนวณ
1. f'cr ตาม ACI 318-19 §26.4.3: ถ้ามี S.D. จากผลทดสอบตั้งแต่ 15 ชุดขึ้นไปจะใช้สูตรจาก S.D. (ถ้าน้อยกว่า 30 ชุดจะคูณ factor เพิ่ม) ถ้าไม่มีใช้ f'c + 7.0 / 8.3 หรือ 1.10f'c + 5.0
2. น้ำและปริมาณอากาศจาก Table 6.3.3
3. w/cm จาก Table 6.3.4(a) แบบ interpolate แล้วเทียบกับ w/cm สูงสุดด้านความคงทน และปริมาณวัสดุประสานขั้นต่ำ
   จากนั้นแบ่ง binder เป็นปูน, fly ash และ slag ตาม % โดยน้ำหนัก
4. ปริมาตรหินจาก Table 6.3.6 (b/b₀ ตาม FM ของทราย)
5. ทรายคำนวณจากปริมาตรที่เหลือ
6. ปรับน้ำหนักวัสดุตามความชื้นหน้างาน (§6.3.10) และคิดน้ำหนักชั่งสำหรับ trial batch
7. สารผสมเพิ่ม: ปริมาณ (cc) = binder (kg) × dose เช่น binder 100 kg × dose 3 = 300 cc
   น้ำที่อยู่ในสารผสม (100 − เนื้อสาร %) จะถูกหักออกจากน้ำที่ชั่ง

## ข้อจำกัด
- ช่วงกำลังที่ใช้ได้ตามตาราง 6.3.4(a): f'cr 15–40 MPa (AE ถึง 35 MPa)
- ไม่รองรับการแปลงกำลังลูกบาศก์ → ทรงกระบอก
- ถ้าใช้ fly ash / slag ยังใช้ตาราง w/c ของปูนปอร์ตแลนด์ล้วน ต้องหาความสัมพันธ์ w/cm–กำลังจาก trial batch
- ไม่ได้นับปริมาตรเนื้อสารของสารผสมเพิ่มในการคำนวณ 1 m³ (มีผลน้อยมาก)
- ผลที่ได้เป็นค่าเริ่มต้นสำหรับ trial batch เท่านั้น ต้องทดลองผสมจริงและให้วิศวกรผู้รับผิดชอบอนุมัติก่อนนำไปใช้
